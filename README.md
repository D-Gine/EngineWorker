# EngineWorker

## Build and Run with
### Env
For this project you need the following environment variables:
```
# ROOM INFORMATIONS
RULESET_ID="aaaaa"
CAMPAIGN_ID="aaaaa"

# DATABASE
DB_HOST=dengine-db-{x.x.x}
DB_PORT=5432
DB_USER=[DB_USER : string]
DB_PWD=[DB_PWD : string]
DB_NAME=dengine

# WORKER-API
VERSION=1.0.0
API_PORT=[API_PORT : int]
GIN_MODE=debug

# NETWORKS
BACK_NETWORK=dengine-back-net
```
